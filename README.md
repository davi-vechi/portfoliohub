# 🚀 PortfolioHUB

O **PortfolioHUB** é uma plataforma centralizada e responsiva desenvolvida para a exibição, organização e gerenciamento de projetos e portfólios digitais. O foco principal deste projeto foi aplicar na prática conceitos rigorosos de controle de versão, automação de deploy, gestão de acessos e segurança da informação através do ecossistema Git e GitHub.

---

## 🛡️ Políticas de Segurança Implementadas
Para garantir a integridade do código e seguir as melhores práticas de mercado, as seguintes barreiras de segurança foram adotadas com o suporte da IA:
* **Autenticação de Dois Fatores (2FA):** Ativada na conta do proprietário administrativo.
* **Proteção da Branch Principal:** Bloqueio de commits diretos na branch `main`, exigindo revisões via Pull Requests para garantir a estabilidade do ambiente de produção.
* **Blindagem de Arquivos (.gitignore):** Configuração preventiva para impedir o envio acidental de arquivos locais de configuração e variáveis sensíveis (como arquivos `.env` ou chaves de API).
* **Manifesto de Segurança (SECURITY.md):** Publicado na raiz do repositório para normatizar o processo de reporte privado e seguro de possíveis vulnerabilidades por parte da comunidade.

---

## ⚙️ Tecnologias e Infraestrutura
* **Linguagem Base:** HTML5 (estruturado de forma nativa e responsiva).
* **Controle de Versão:** Git e GitHub (Versionamento semântico baseado em commits padronizados).
* **Ambiente de Produção (Deploy):** GitHub Pages (Hospedagem estática automatizada a partir da raiz da branch `main` com protocolo HTTPS ativo).

## 🧪 Rotina de Testes e Homologação
O deploy foi validado através de uma rotina estrita de testes dividida em três frentes principais:
1. **Interface e Responsividade:** Validação visual do comportamento dos elementos e carregamento fluido em múltiplas telas e navegadores.
2. **Conectividade:** Verificação prática de que todos os hiperlinks redirecionam o usuário de forma precisa para os respectivos repositórios e perfis.
3. **Integridade de Código:** Monitoramento de sintaxe para certificar a ausência de erros em tempo de execução.
